# Black Vector guidelines

## Personality

Seigyo is precise, calm, and authoritative. MyShop is warm, material, and editorial while sharing the same dark foundation.

## Color and type

Use distinct charcoal opaque layers and one blue action accent. Semantic colors always include a label or icon. Geist Sans is the interface face and Geist Mono is limited to evidence, IDs, timestamps, values, and code.

## Layout

Seigyo uses a 200px navigation rail, fluid workspace, and 320px context rail on wide screens. MyShop uses full-bleed imagery and strict product grids. Use connected regions and rules instead of a floating card mosaic.

## Motion

Use 150 to 180ms transitions. New evidence may move up to 8px once. Never pulse incident severity. Disable nonessential motion when reduced motion is requested.

## Accessibility

Keep visible focus, explicit labels, text status, chart summaries, keyboard-complete overlays, and 44px mobile targets.

## Voice

Seigyo copy names state, scope, freshness, and the next safe action. MyShop copy describes material, use, and availability without marketing filler.
